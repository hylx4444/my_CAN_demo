# UART 协议 v1

物理串口：115200 / 8N1 / 3.3 V TTL。当前实现 F2800157 → ESP32-S2 的周期遥测，保持 v1 帧布局兼容；反向命令、应答及 CANopen 服务未实现。

所有多字节数值均为小端。本文“字节”指线路上的 8 位 octet。

## 帧格式

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 2 | 帧头 A5 5A |
| 2 | 1 | 版本，固定 01 |
| 3 | 1 | 消息类型，01=遥测 |
| 4 | 2 | 帧序号，无符号，65535 后回绕 |
| 6 | 2 | payload 长度，遥测固定 22，通用最大 48 |
| 8 | N | payload |
| 8+N | 2 | CRC16，小端，低字节先发 |

遥测总长 32 字节。CRC 为 **CRC-16/CCITT-FALSE**：多项式 0x1021、初值 0xFFFF、不反射、异或输出 0；覆盖版本（偏移2）至 payload 末尾，不含帧头和 CRC 本身。ASCII `123456789` 校验值为 0x29B1。

## 遥测 payload

| payload 偏移 | 长度 | 类型 | 含义 |
| --- | --- | --- | --- |
| 0 | 4 | uint32 | 源端运行毫秒，约 49.7 天回绕 |
| 4 | 2 | int16 | 温度，0.01 °C，二进制补码 |
| 6 | 2 | uint16 | 相对湿度，0.01 %RH，范围 0..10000 |
| 8 | 4 | uint32 | CAN 应用数据帧发送计数，真实采集为 0，硬件 ACK 不计入 |
| 12 | 4 | uint32 | 通过校验的传感器 CAN 帧计数；模拟源中为模拟计数 |
| 16 | 4 | uint32 | 拒绝报文、邮箱覆盖事件、Bus-off 事件之和 |
| 20 | 2 | uint16 | 状态位 |

状态位：bit0=采样有效，bit1=模拟数据，bit2=旧版硬件回环源，bit3=电脑模拟源，bit4=ESP 本地模拟源，bit5=真实传感器源，bit6=CAN Bus-off。其余位预留。真实正常值为 0x0021；未接入/超时为 0x0020；总线离线为 0x0060。电脑正常为 0x000B，ESP 本地正常为 0x0013。

F2800157 每 200ms 发送一帧状态。没有传感器或 CAN 失败时仍上报，保持 UART 链路可观测。无效帧中可保留上次温湿度，接收方必须检查有效位，不能当作当前测量。

## 接收、显示与恢复

- 流式解析，支持任意分段与连续帧。
- 非法版本或长度、CRC 失败后向后扫描帧头，保留可能属于下一帧的数据。
- ESP 超过 200 ms 未收到字节后丢弃残留半帧，错误累计计数保留。
- 157 超过 1000ms 未收到有效传感器帧，或发生 Bus-off，就清除采样有效位。坏帧和 UART 状态上报都不会刷新 CAN 采样时间。
- 超过 3500 ms 未收到可解码遥测帧，链路离线；测量有效位清零也会使显示值无效。
- HTTP 接口有效数据返回数值，无效或过期时温湿度返回 JSON `null`，网页显示 `--`。
- 最新帧以接收先后更新；序号用于观察，不把源端重启或序号回绕误认为永久丢包。
- HTTP 的 online 表示 UART 链路，sensor_online 表示有效真实采样，bus_off 表示 CAN 总线离线。source 为 c2000-sensor 时是实际传感器路径；其他已知模拟源都明确标识。

## C28x 数据表示

公共模块用 `uint16_t` 数组中的低 8 位表示每个线路字节，编码后的返回值是 octet 数量。F2800157 通过 SCI 逐个写入低 8 位；ESP 将 `uint8_t` 接收缓冲区逐个送入解析器。

禁止直接发送结构体或 `memcpy` 结构体到线路：两种 CPU 的 char 宽度、对齐和 sizeof 语义不同。线上的顺序由显式移位和掩码定义。

## 传感器自定义 CAN 报文

100 kbit/s，29 位扩展数据帧，ID=0x18FF0000，DLC=8。Byte0 为地址，默认 1；Byte1/2 为有符号温度低/高字节，单位 0.1°C；Byte3/4 为湿度低/高字节，单位 0.1%RH；Byte5..7 为 NA，程序不要求为零。

样例 01 D9 00 1C 02 00 00 00 表示 21.7°C、54.0%RH。进入 UART 前乘以 10，仍使用原 v1 的 0.01 单位。先用 32 位计算再验证范围，超出 int16 百分之一度表示范围或湿度不在 0..100%RH 时拒绝该帧，避免溢出。

传感器约每 100ms 主动上报，不发送 SDO、NMT 或读取请求。本工程未实现 CANopen。ESP/电脑的本地模拟模型只用于软件验证，不发送到外部 CAN 总线。
